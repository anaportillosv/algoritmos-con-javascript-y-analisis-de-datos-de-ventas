Ana Portillo | Analytics & Dashboard Futurista   Este código implementa un dashboard analítico y futurista desarrollado con una estética de alta tecnología en tonos oscuros, dorados y morados neón. Está compuesto por tres archivos principales que trabajan en conjunto:   Estructura HTML (Ana Portillo html.html): Define la interfaz visual de la aplicación, integrando un encabezado de marca corporativa, una barra de búsqueda interactiva conectada a un asistente virtual de consultas, un panel de tarjetas con KPIs dinámicos y un contenedor principal para gráficos interactivos impulsados por Chart.js.   Estilos CSS (Ana PortilloCodigoCSS.css): Proporciona el diseño visual mediante técnicas modernas como Glassmorphism (efectos de cristal esmerilado), efectos de resplandor o glow en el fondo, tipografías futuristas (Orbitron y Plus Jakarta Sans) y una estructura adaptable y limpia.   Lógica JavaScript (Ana PortilloJavaScript.js): Gestiona los datos de ventas mensuales (desde enero hasta junio), calcula de forma automática métricas clave (total acumulado, promedio mensual, máximo y mínimo histórico), inicializa las gráficas dinámicas y controla el motor de búsqueda inteligente capaz de filtrar información o responder consultas de texto en tiempo real.
